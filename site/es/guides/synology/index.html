OwnMedia en Synology

Jellyfin en Container Manager y el plugin de OwnMedia desde el catálogo de plugins. No hace falta el instalador de Windows. Una media hora, una sola vez.

Lo que consigues: películas, series, música y fotos del NAS en tu teléfono, copia de fotos del teléfono al NAS, invitaciones para amigos y acceso desde internet.

Los menús de DSM, Jellyfin y la app aparecen en inglés, como se llaman en la interfaz en inglés.

1. ¿Puede este NAS ejecutarlo?

Abre el Package Center y busca Container Manager. Si está, sigue esta guía.

Si no está (modelos pequeños), Jellyfin existe como paquete de SynoCommunity, pero suele ser una versión antigua, y el plugin de OwnMedia necesita Jellyfin 12.1 o posterior. En ese caso, escríbenos y buscaremos otra forma.

2. Carpetas

La carpeta compartida docker aparece al instalar Container Manager. En File Station, crea:

  • docker/jellyfin/config y docker/jellyfin/cache para el propio Jellyfin;
  • una carpeta para las fotos copiadas desde los teléfonos, por ejemplo photo/OwnMedia.

Deja tus películas, series y música donde están; más abajo solo necesitas las rutas de sus carpetas (por ejemplo /volume1/video, /volume1/music). File Station muestra la ruta: clic derecho en una carpeta → Properties.

Cada carpeta tiene su propio número de volumen: en un NAS con varios volúmenes, docker puede estar en /volume1 y las películas y fotos en /volume4. En el paso 3, escribe las rutas exactamente como las muestra Properties.

3. Jellyfin en Container Manager

Container Manager → Project → Create:

  • Project name: ownmedia
  • Path: /volume1/docker/jellyfin
  • Source: Create docker-compose.yml, y pega el archivo de abajo. Cambia las rutas a la izquierda de los dos puntos por las tuyas del paso 2, con el número de volumen incluido; no toques la parte derecha.
services:
  jellyfin:
    image: jellyfin/jellyfin:12.1
    container_name: jellyfin
    # La red del propio NAS: los teléfonos de la Wi-Fi encuentran el servidor solos ("Add your server").
    network_mode: host
    restart: unless-stopped
    volumes:
      - /volume1/docker/jellyfin/config:/config
      - /volume1/docker/jellyfin/cache:/cache
      - /volume1/video:/media/video:ro
      - /volume1/music:/media/music:ro
      - /volume1/photo/OwnMedia:/media/photos

Next → Done. Container Manager descarga Jellyfin (unos 300 MB) y lo arranca.

:ro significa solo lectura: Jellyfin no puede cambiar nada de tus películas ni de tu música. La carpeta de fotos no lleva :ro, porque allí se escriben las copias del teléfono.

4. Primera configuración de Jellyfin

En un navegador de tu ordenador, abre http://<dirección del NAS>:8096, la misma dirección con la que abres DSM, por ejemplo http://192.168.1.50:8096:

  1. Idioma → crea un usuario: un nombre y una contraseña (los escribirás en el teléfono).
  2. Bibliotecas: «Movies» → carpeta /media/video, «Music» → /media/music, y si quieres «Photos» → /media/photos.
  3. Acceso remoto: déjalo activado. Listo.

5. El plugin de OwnMedia

En Jellyfin: Dashboard → Plugins → Manage Repositories → +:

  • Nombre: OwnMedia
  • URL:
https://raw.githubusercontent.com/3dengineering01-star/Homeplayer/main/jellyfin-repo/manifest.json

Guarda → vuelve a Plugins, elige el filtro All (o busca) → Homeplay Backup → Install. Después reinicia Jellyfin con el botón Restart de la página principal del Dashboard (no en Plugins). Tras reiniciar, el plugin aparece en el filtro Installed, marcado como Active.

En los ajustes de Homeplay Backup, pon la carpeta para las copias de fotos: /media/photos.

Jellyfin muestra solo las versiones nuevas del plugin, en Plugins.

6. El teléfono

En OwnMedia, toca Add your server: el NAS se encuentra solo si el teléfono está en la misma Wi-Fi. Si no, escribe <dirección del NAS>:8096. Usa el nombre y la contraseña del paso 4.

Una página con código QR para teléfonos: http://<dirección del NAS>:8096/Homeplay/Phone.

Si http://<dirección del NAS>:8096 no se abre en el navegador, o el teléfono no encuentra el NAS, y el cortafuegos de DSM está activo (Control Panel → Security → Firewall), añade a su perfil una regla Allow para los puertos 8096 (TCP) y 7359 (UDP; los teléfonos lo usan para encontrar el servidor en la Wi-Fi).

7. Acceso desde internet e invitaciones para amigos (Tailscale)

Solo Jellyfin (puerto 8096) se abre a internet; DSM sigue cerrado y en el router no cambia nada.

  1. Package Center → Tailscale → instalar → abrir → inicia sesión con tu cuenta de Tailscale. Si Tailscale ya estuvo en este NAS, verás en su lugar «Your device’s key has expired → Reauthenticate»: es normal, púlsalo e inicia sesión.
  2. Una carpeta para los resultados de las tareas (hace falta en el paso 4): en File Station crea, por ejemplo, docker/tasklogs. Después Control Panel → Task Scheduler → Settings → Save output results → esta carpeta.
  3. Task Scheduler → Create → Triggered Task → User-defined script:
    • pestaña General: nombre OwnMedia Funnel, usuario root, evento Boot-up, Enabled;
    • pestaña Task Settings, script:
    /var/packages/Tailscale/target/bin/tailscale funnel --bg 8096

    Al guardar, DSM avisa de una tarea que se ejecuta como root y pide la contraseña de tu cuenta de DSM (con la que has iniciado sesión en DSM). Tenla a mano.

  4. Selecciona la tarea → Run. El resultado está en la carpeta del paso 2: <carpeta>/OwnMedia Funnel/<hora>/output.log. Debería decir: 
    Available on the internet:
https://<nombre del NAS>.<tu tailnet>.ts.net/
|-- proxy http://127.0.0.1:8096

    Si en su lugar muestra un enlace para activar Funnel, ábrelo, pulsa Enable Funnel y vuelve a ejecutar la tarea. El ajuste se guarda; la tarea al arrancar es una red de seguridad para cuando el NAS se reinicia.

  5. Comprueba: abre https://<nombre del NAS>.<tu tailnet>.ts.net/Homeplay/Phone en un teléfono con la Wi-Fi desactivada. En los primeros minutos puede que la dirección a veces no se abra (un error de conexión segura): espera 2–3 minutos.
  6. En OwnMedia: el menú del servidor ⋮ → Share with friends → I have an address already → esta dirección.

Probado en un RS2423+ con DSM 7.3.2 y el paquete de Tailscale 1.58.2.

Si el vídeo se corta

Primero averigua si el servidor convierte el vídeo: mientras se reproduce, abre Jellyfin en un navegador → Dashboard → el icono «i» junto a la reproducción. Direct playing significa que el servidor envía el archivo tal cual, y el cuello de botella es el camino hasta el teléfono, no el NAS.

Lo rápido que es ese camino:

  • En casa, añade el NAS otra vez en OwnMedia con su dirección local (<dirección del NAS>:8096) y mira por ella: el vídeo va directamente por la Wi-Fi, a toda velocidad.
  • Fuera de casa, instala la app de Tailscale en el teléfono e inicia sesión con la misma cuenta que en el NAS. Así la dirección https://….ts.net va por Tailscale y no por Funnel.
  • Tailscale conecta el teléfono con el NAS directamente o, cuando el router no lo permite, a través de su servidor de relé. Por el relé, igual que por Funnel (para amigos), consigues unos 20 Mbit/s. Basta para películas y series normales en 1080p (5–10 Mbit/s), pero no para archivos 4K pesados: el 4K a 60 fotogramas por segundo necesita unos 40 Mbit/s y se cortará («reproduce 2 segundos, espera 2 segundos»).
  • Si la conexión es directa lo muestra un ordenador del mismo tailnet: tailscale ping <nombre del NAS>; «via DERP» significa a través del relé. Una conexión directa suele llegar con un paquete de Tailscale reciente en el NAS (el del Package Center puede ser antiguo; el nuevo está en pkgs.tailscale.com), o con el puerto UDP 41641 abierto en el router del NAS hacia el NAS (por él solo pasa el tráfico cifrado de Tailscale; DSM sigue cerrado).

Qué hacer con archivos pesados sin conexión directa:

  • descárgalos antes, mientras estás en casa: pulsación larga → Download, y después míralos desde Downloads;
  • elige una calidad más baja (1080p) en el reproductor: el servidor convierte el vídeo. Un NAS sin tarjeta gráfica convierte con el procesador y puede no dar abasto con 4K.

La app para tus amigos

No hay nada que configurar: la página de invitación y el código QR llevan a tus amigos a descargar la app más reciente desde ownmedia.app. Hace falta el plugin 1.8 o posterior; Jellyfin ofrece la actualización en Dashboard → Plugins.

Quitar OwnMedia del NAS

  1. Container Manager → Project → ownmedia → Stop → Delete, y después Image → jellyfin/jellyfin → Delete (unos 1,7 GB).
  2. Task Scheduler → OwnMedia Funnel → Delete. Esto no desactiva el acceso desde internet: Funnel sigue activo en Tailscale (la dirección se abre, con un error). Para desactivarlo, o bien quita el paquete de Tailscale (Package Center → Tailscale → Uninstall, y después borra el NAS de la lista Machines en la web de Tailscale), o bien, si necesitas Tailscale para otra cosa, ejecuta una vez una tarea como root: /var/packages/Tailscale/target/bin/tailscale funnel --https=443 off.
  3. File Station: borra docker/jellyfin y docker/tasklogs. Si la carpeta compartida docker queda vacía, puedes borrarla en Control Panel → Shared Folder (la próxima vez que crees un proyecto tendrás que volver a crearla).
  4. Tus películas, tu música y las copias de fotos no se tocan: borra tú mismo la carpeta de copias si no la necesitas.
  5. En OwnMedia, en el teléfono: el menú del servidor ⋮ → quitar el servidor.
