Server for Windows

OwnMediaSetup.exe installs Jellyfin, adds your folders, puts in the OwnMedia plugin and, if you like, opens the server to the internet. At the end it shows a QR code for your phone.

  • Windows 10 or 11, 64-bit
  • Administrator rights, internet during setup
  • Already have Jellyfin? Only the plugin is added

NAS and Docker

Run Jellyfin 12.1 or newer in a container, then add the OwnMedia plugin catalogue in Jellyfin: Dashboard → Plugins → Manage Repositories → +.

What the plugin does

“Homeplay Backup” is the server side of OwnMedia: it receives the photo backup from phones, makes invite links for friends and shows the page with the QR code for connecting a phone. Its code is open, under the GPL (source). New versions show up in Jellyfin by themselves, under Plugins.
