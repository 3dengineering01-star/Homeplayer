Guides

Installez le serveur une fois, ensuite tout se passe dans l’app. Choisissez où se trouvent vos films et votre musique.

PC Windows

Un seul programme : Jellyfin, vos dossiers, l’accès depuis Internet et un QR code pour le téléphone. Le démarrage le plus rapide.

NAS Synology

Jellyfin dans Container Manager, le plugin OwnMedia depuis le catalogue, Tailscale pour Internet. Environ une demi-heure.

Docker sous Linux ou sur un autre NAS

Le même fichier compose et le même catalogue de plugins, pour toute machine qui fait tourner Docker.

Regarder sur la télé

Envoyez un film du téléphone vers une télé connectée de votre Wi-Fi et servez-vous du téléphone comme télécommande.

Hors de chez vous et amis

Comment OwnMedia atteint votre serveur par Internet, comment aller plus vite, comment fonctionnent les invitations et comment retirer l’accès à quelqu’un.
