Serveur pour Windows

OwnMediaSetup.exe installe Jellyfin, ajoute vos dossiers, met en place le plugin OwnMedia et, si vous le souhaitez, ouvre le serveur sur Internet. À la fin, il affiche un QR code pour votre téléphone.

  • Windows 10 ou 11, 64 bits
  • Droits d’administrateur, Internet pendant l’installation
  • Vous avez déjà Jellyfin ? Seul le plugin est ajouté

Version 0.3.13, 26 Mo. SHA-256: bd54e4d5ef11a54a8e6793ba451914f8c728282d1a8a18dbfedd86e2522d3d50

Le programme d’installation n’est pas encore signé numériquement : Windows peut afficher « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Ce que fait le plugin

« Homeplay Backup » est le côté serveur d’OwnMedia : il reçoit la sauvegarde des photos des téléphones, crée les liens d’invitation pour vos amis et affiche la page avec le QR code pour connecter un téléphone. Son code est ouvert, sous licence GPL (code source). Les nouvelles versions apparaissent d’elles-mêmes dans Jellyfin, sous Plugins.
