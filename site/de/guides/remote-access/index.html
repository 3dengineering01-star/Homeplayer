Unterwegs und Freunde

Schau deinen Server von überall und teile ihn mit den Leuten, die du auswählst, ohne Ports an deinem Router zu öffnen.

So funktioniert’s

Zu Hause spricht das Handy über dein WLAN mit dem Server. Fürs Internet nutzt OwnMedia Tailscale Funnel: Tailscale, ein kostenloser Dienst, gibt deinem Server eine sichere Adresse wie https://my-pc.tail1234.ts.net. Darüber ist nur Jellyfin erreichbar; sonst wird nichts auf dem Computer oder NAS geöffnet, und an deinem Router änderst du nichts.

  • Windows: Lass im Installationsprogramm „Let friends watch from anywhere“ angehakt. Es installiert Tailscale, du meldest dich einmal im Browser an, und es schaltet Funnel ein. Beim ersten Mal nicht angehakt? Starte OwnMediaSetup noch einmal. Anleitung für Windows.
  • Synology: Schritt 7 der Synology-Anleitung.
  • Docker: ein Befehl auf dem Host.

Hast du schon einen eigenen Weg, ein VPN oder eine eigene Domain? OwnMedia funktioniert mit jeder Adresse, die dein Handy erreicht.

Du, unterwegs

Füge den Server in OwnMedia mit seiner Adresse https://….ts.net hinzu, oder behalte die Heimadresse und schalte die Tailscale-App auf deinem Handy ein, angemeldet mit demselben Konto wie der Server. Mit der Tailscale-App ist die Verbindung meist schneller (siehe Geschwindigkeit).

Im Mobilfunknetz kann OwnMedia Datenvolumen sparen: Stell eine Qualität fürs WLAN und eine fürs Mobilfunknetz ein (Zahnrad-Symbol in der Serverliste). „Auto“ misst die Verbindung vor einem Video, und der Server wandelt nur um, was nicht hindurchpassen würde.

Freunde einladen

  1. Öffne in OwnMedia das Menü des Servers ⋮ → Share with friends.
  2. Gib den Namen des Freundes ein und wähle die Mediatheken zum Teilen. Fotos sind nicht dabei, außer du fügst sie hinzu.
  3. Schick den Link über einen beliebigen Messenger oder per E-Mail.
  4. Der Freund öffnet den Link auf seinem Android-Handy, installiert OwnMedia, falls er es noch nicht hat, und fügt deinen Server mit einem Tippen hinzu: Er muss keinen Namen und kein Passwort eintippen.

Der Link funktioniert einmal, 7 Tage lang: Wer ihn zuerst benutzt, bekommt den Zugang. Schick ihn nur an den Freund, für den er gedacht ist.

Ein Freund kann nur schauen und hören: Er kann nichts löschen, keine Fotos auf deinem Server sichern und ihn nicht weiter teilen. Teile nur, was du teilen darfst.

Du hast schon einen Einladungslink? In OwnMedia: Add your server → Have an invite link? und füge ihn ein.

Ein eigener Server

Freunde, denen es gefällt, können sich einen eigenen Server einrichten: Die Einladungsseite und die App zeigen drei Schritte, und Send the link to my computer schickt ihnen das Windows-Installationsprogramm von deinem Server.

Wer Zugang hat

In Share with friends zeigt die Liste Who has access jeden Freund: das Handy, mit dem er beigetreten ist, wann er den Server zuletzt genutzt hat und was er gerade schaut. End access entfernt seine Anmeldung sofort von deinem Server, und seine App sagt ihm, dass der Besitzer den Zugang geschlossen hat. (Braucht das Plugin in Version 1.7 oder neuer.)

Geschwindigkeit

  • Über Funnel (so verbinden sich Freunde) und über das Relay von Tailscale, wenn keine direkte Verbindung möglich ist, bekommst du etwa 20 Mbit/s. Das reicht für normale Filme und Serien in 1080p (5–10 Mbit/s), aber nicht für schwere 4K-Dateien: 4K mit 60 Bildern pro Sekunde braucht etwa 40 Mbit/s.
  • Mit der Tailscale-App auf dem Handy ist die Verbindung oft direkt und so schnell, wie das Internet an beiden Enden erlaubt.
  • Für schwere Dateien unterwegs: Lade sie zu Hause herunter (lang drücken → Download), oder wähle im Player eine niedrigere Qualität, dann wandelt der Server das Video um.
