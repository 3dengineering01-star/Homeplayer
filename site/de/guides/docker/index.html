OwnMedia mit Docker

Für einen Linux-Rechner oder ein beliebiges NAS mit Docker Compose. Auf Synology folge stattdessen der Schritt-für-Schritt-Anleitung für Synology.

Menüs von Jellyfin und der App stehen hier auf Englisch, so wie sie in der englischen Oberfläche heißen.

1. Jellyfin

Lege Ordner für die Einstellungen und den Cache von Jellyfin an und einen für Fotos, die von Handys gesichert werden. Dann eine docker-compose.yml; ersetze die Pfade links vom Doppelpunkt durch deine:

services:
  jellyfin:
    image: jellyfin/jellyfin:12.1
    container_name: jellyfin
    # Das eigene Netz des Hosts: Handys im WLAN finden den Server von selbst ("Add your server").
    network_mode: host
    restart: unless-stopped
    volumes:
      - /srv/jellyfin/config:/config
      - /srv/jellyfin/cache:/cache
      - /srv/media/video:/media/video:ro
      - /srv/media/music:/media/music:ro
      - /srv/media/photos/OwnMedia:/media/photos

Starte sie mit docker compose up -d. :ro hält deine Filme und Musik schreibgeschützt; der Fotoordner muss beschreibbar sein, weil Backups vom Handy dort landen.

Das OwnMedia-Plugin braucht Jellyfin 12.1 oder neuer. network_mode: host lässt Handys den Server in deinem WLAN finden (UDP-Port 7359). Ist eine Firewall aktiv, erlaube TCP 8096 und UDP 7359.

2. Ersteinrichtung

Öffne http://<Serveradresse>:8096 im Browser, lege einen Benutzer an (Name und Passwort fürs Handy) und füge Mediatheken hinzu: Movies → /media/video, Music → /media/music und, wenn du willst, Photos → /media/photos.

3. Das OwnMedia-Plugin

In Jellyfin: Dashboard → Plugins → Manage Repositories → +, Name OwnMedia, URL:

https://raw.githubusercontent.com/3dengineering01-star/Homeplayer/main/jellyfin-repo/manifest.json

Dann Plugins → Filter All → Homeplay Backup → Install, und starte Jellyfin auf der Hauptseite des Dashboard neu. Stelle in den Einstellungen des Plugins den Fotoordner auf /media/photos.

4. Das Handy

Tippe in OwnMedia auf Add your server; im selben WLAN wird er von selbst gefunden, sonst tippe <Serveradresse>:8096 ein. Eine Seite mit QR-Code für Handys: http://<Serveradresse>:8096/Homeplay/Phone.

5. Zugriff aus dem Internet

Installiere Tailscale auf dem Host, melde dich an und öffne den Port von Jellyfin mit Funnel:

sudo tailscale funnel --bg 8096

Der Befehl zeigt die Adresse, https://<Rechner>.<dein Tailnet>.ts.net/. Beim ersten Mal bittet Tailscale dich vielleicht, Funnel im Browser zu aktivieren. Nur Port 8096 wird geöffnet; am Router ändert sich nichts. Dann in OwnMedia: das Menü des Servers ⋮ → Share with friends → I have an address already → diese Adresse.

Erreichst du den Server schon anders, mit eigener Domain und Reverse Proxy oder per VPN? Dann nimm diese Adresse. Mehr unter Unterwegs und Freunde.

Die App für Freunde

Nichts einzurichten: Einladungsseiten und der QR-Code schicken Freunde zum Download der neuesten App von ownmedia.app. Dafür braucht es das Plugin 1.8 oder neuer; Jellyfin bietet das Update unter Dashboard → Plugins an.

OwnMedia entfernen

  1. docker compose down im Ordner mit der Compose-Datei, dann docker image rm jellyfin/jellyfin:12.1.
  2. Schalte den Zugriff aus dem Internet ab: sudo tailscale funnel --https=443 off. Jellyfin anzuhalten reicht dafür nicht: Funnel bleibt in Tailscale selbst an (die Adresse öffnet sich, mit einem Fehler), bis du es abschaltest oder Tailscale entfernst und den Rechner aus der Liste Machines auf der Tailscale-Website löschst.
  3. Lösche die Ordner für Einstellungen und Cache von Jellyfin. Deine Filme, Musik und Foto-Backups bleiben unberührt.
  4. In OwnMedia auf dem Handy: das Menü des Servers ⋮ → Server entfernen.
