# Homeplay Backup — плагин Jellyfin

Принимает фото и видео из приложения OwnMedia и складывает их в папку на сервере по месяцам съёмки:
`<папка>\<год-месяц>\<файл>`, например `D:\Фото\2026-10\PXL_20261007.jpg`. Дата файла — дата съёмки.
Если имя занято, к нему добавляется номер: `IMG.jpg`, `IMG (2).jpg`.

- С версии 1.1 при первом обращении телефона плагин сам перекладывает фото, сохранённые версией 1.0
  в `<папка>\<пользователь>\<телефон>\<год>\<месяц>`, в папки месяцев и удаляет опустевшие папки.
  Трогает только файлы, которые сам туда положил; чужие файлы остаются на месте. Делается один раз.

- Загрузка кусками с докачкой после обрыва. Уже полученный файл второй раз не принимается.
- Служебные данные (недокачанные файлы, список полученных) лежат в `<папка>\.homeplay`, отдельно для каждого
  пользователя и телефона.
- Пока администратор не задал папку, загрузка отклоняется.

## API (нужен вход пользователя Jellyfin)

- `GET /HomeplayBackup/Info` → `{ Version, Configured }`.
- `POST /HomeplayBackup/Check` с телом `{ Device, Ids: [...] }` → для каждого id `{ Id, Done, Offset }`.
- `PUT /HomeplayBackup/Upload?device=&id=&name=&size=&takenAt=&offset=`, тело — байты куска (до 64 МБ).
  Ответ `{ Id, Done, Offset }`. Если кусок начинается не там, где кончается копия на сервере, ответ 409 с правильным `Offset`.

## Телефон (с версии 1.2, без входа)

- `GET /Homeplay/Phone` — страница для компьютера после установки: QR-код со ссылкой на приложение и что делать
  дальше. Открытая на самом компьютере (`localhost`), она подставляет в код адрес компьютера в домашней сети.
- С версии 1.8 QR-код и страница приглашения ведут за приложением на сайт:
  `https://ownmedia.app/download/OwnMedia.apk` (`PhoneLink.AppUrl`) — там всегда последняя версия.
- `GET /Homeplay/App` — файл `OwnMedia.apk` (или другой `*.apk`) рядом с dll плагина, для ссылок и QR-кодов,
  сделанных раньше; без файла — 404.
- QR-код рисует QRCoder (MIT): `QRCoder.dll` лежит в папке плагина рядом с его dll.

## Поделиться с друзьями (с версии 1.3)

Владелец (администратор Jellyfin) делает ссылку-приглашение на выбранные библиотеки. Друг открывает её на
телефоне, ставит OwnMedia (если его нет) и одним нажатием добавляет сервер: для него заводится свой
пользователь Jellyfin — скрытый, не администратор, видит только эти библиотеки, ничего не удаляет и не
загружает фото на компьютер владельца. Ссылка срабатывает один раз; приглашение можно забрать — тогда
пользователь друга удаляется. Друг поделиться чужим сервером не может: всё про приглашения доступно только
администратору.

С версии 1.9 ссылка-приглашение ведёт на сайт, а не на компьютер владельца:
`https://ownmedia.app/join.html#s=<адрес сервера>&n=<имя>&c=<код>` (`SharingStore.JoinLink`, страница —
`landing/join.html`). Приложение друг скачивает с сайта; адрес сервера и код стоят после `#`, браузер их на
сайт не отправляет. Смотреть и слушать друг потом будет напрямую с компьютера владельца, поэтому компьютер и
его адрес в интернете должны работать. Страница копирует приглашение, и приложение 0.3.16+ при первом
открытии подхватывает его само.

Друзья заходят на сервер через интернет: адрес задаёт владелец (например, Tailscale Funnel
`https://<компьютер>.<сеть>.ts.net`). Состояние — в `sharing.json` в папке данных плагина, отдельно от его
настроек.
Если адреса ещё нет, плагин берёт тот, что оставил установщик после включения Tailscale Funnel
(`C:\ProgramData\Homeplay\public-url.txt`), один раз: адрес, который владелец стёр сам, не возвращается.

- `GET/POST /Homeplay/Sharing` (администратор) — адрес в интернете, библиотеки, приглашения.
- `POST /Homeplay/Invites` (администратор) `{ Friend, Libraries: [id], Days }` → приглашение со ссылкой.
- `DELETE /Homeplay/Invites/{code}` (администратор) — забрать приглашение и доступ.
- `GET /Homeplay/Join/{code}` (без входа) — страница для друга на самом сервере: «Open in OwnMedia» или скачать
  приложение. С версии 1.9 приглашения ссылаются на сайт (см. ниже), эта страница остаётся для старых ссылок.
- `POST /Homeplay/Join` (без входа) `{ Code, DeviceId, DeviceName }` → `{ ServerName, UserId, UserName, AccessToken }`.

## Свой сервер для друга (с версии 1.4)

Страница приглашения под основной карточкой показывает «Your own OwnMedia»: три шага, как сделать такой же
сервер у себя. Установщик `OwnMediaSetup.exe` кладёт свою копию рядом с dll плагина, и сервер отдаёт её
друзьям — так установщик передаётся от друга к другу. Без файла страница просит взять его у пригласившего.

- `GET /Homeplay/Setup` (без входа) — `OwnMediaSetup.exe` из папки плагина, или 404.

## Сборка и тесты

```bash
dotnet test server/Jellyfin.Plugin.HomeplayBackup.Tests
dotnet build server/Jellyfin.Plugin.HomeplayBackup -c Release
```

## Установка вручную

1. Скопировать `Jellyfin.Plugin.HomeplayBackup.dll` и `QRCoder.dll` из `bin/Release/net10.0` в
   `C:\ProgramData\Jellyfin\Server\plugins\Homeplay Backup_1.0.0.0\`.
2. Перезапустить Jellyfin.
3. Панель управления → Плагины → Homeplay Backup: указать папку для фото.

Обновление: остановить Jellyfin, заменить `Jellyfin.Plugin.HomeplayBackup.dll` в той же папке плагина новой,
запустить Jellyfin. Номер версии в панели Jellyfin берёт из `meta.json` в папке плагина (и имени папки), а не
из dll: после замены dll панель может показывать старый номер, на работу это не влияет. Чтобы номер был
верным, поправить `"version"` в `meta.json` до запуска Jellyfin.

## Каталог модулей (NAS, Docker, Linux)

Модуль работает на любом Jellyfin 12.1+, не только на Windows. Для установки из интерфейса Jellyfin есть
каталог: Панель управления → Плагины → Каталог → Репозитории → адрес
`https://raw.githubusercontent.com/3dengineering01-star/Homeplayer/main/jellyfin-repo/manifest.json`.
Собирается `tools/make_plugin_repo.sh` (zip без APK и установщика). Проверено на Jellyfin 12.1 под Linux:
установка из каталога, статус «Активен», приглашения, страница телефона. Пошагово для Synology —
`docs/synology.md`.
