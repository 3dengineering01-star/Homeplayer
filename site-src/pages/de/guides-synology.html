OwnMedia auf Synology

Jellyfin im Container Manager und das OwnMedia-Plugin aus dem Plugin-Katalog. Kein Windows-Installationsprogramm nötig. Etwa eine halbe Stunde, einmal.

Was du bekommst: Filme, Serien, Musik und Fotos vom NAS auf deinem Handy, Foto-Backup vom Handy aufs NAS, Einladungen für Freunde und Zugriff aus dem Internet.

Menüs von DSM, Jellyfin und der App stehen hier auf Englisch, so wie sie in der englischen Oberfläche heißen.

1. Kann dieses NAS das?

Öffne das Package Center und such nach Container Manager. Ist er da, folge dieser Anleitung.

Ist er nicht da (kleinere Modelle), gibt es Jellyfin als Paket von SynoCommunity, aber meist in einer alten Version, und das OwnMedia-Plugin braucht Jellyfin 12.1 oder neuer. Dann schreib uns, und wir finden einen anderen Weg.

2. Ordner

Der freigegebene Ordner docker erscheint, wenn Container Manager installiert ist. Lege in der File Station an:

  • docker/jellyfin/config und docker/jellyfin/cache für Jellyfin selbst;
  • einen Ordner für Fotos, die von Handys gesichert werden, zum Beispiel photo/OwnMedia.

Lass deine Filme, Serien und Musik, wo sie sind; unten brauchst du nur die Pfade zu ihren Ordnern (zum Beispiel /volume1/video, /volume1/music). Die File Station zeigt den Pfad: Rechtsklick auf einen Ordner → Properties.

Jeder Ordner hat seine eigene Volume-Nummer: Auf einem NAS mit mehreren Volumes kann docker auf /volume1 liegen und Filme und Fotos auf /volume4. Tippe die Pfade in Schritt 3 genau so ein, wie Properties sie zeigt.

3. Jellyfin im Container Manager

Container Manager → Project → Create:

  • Project name: ownmedia
  • Path: /volume1/docker/jellyfin
  • Source: Create docker-compose.yml, und füge die Datei unten ein. Ersetze die Pfade links vom Doppelpunkt durch deine aus Schritt 2, samt Volume-Nummer; die rechte Seite bleibt, wie sie ist.
services:
  jellyfin:
    image: jellyfin/jellyfin:12.1
    container_name: jellyfin
    # Das eigene Netz des NAS: Handys im WLAN finden den Server von selbst ("Add your server").
    network_mode: host
    restart: unless-stopped
    volumes:
      - /volume1/docker/jellyfin/config:/config
      - /volume1/docker/jellyfin/cache:/cache
      - /volume1/video:/media/video:ro
      - /volume1/music:/media/music:ro
      - /volume1/photo/OwnMedia:/media/photos

Next → Done. Container Manager lädt Jellyfin herunter (etwa 300 MB) und startet es.

:ro heißt schreibgeschützt: Jellyfin kann an deinen Filmen und deiner Musik nichts ändern. Der Fotoordner hat kein :ro, weil Backups vom Handy dorthin geschrieben werden.

4. Ersteinrichtung von Jellyfin

Öffne im Browser auf deinem Computer http://<NAS-Adresse>:8096, dieselbe Adresse, unter der du DSM öffnest, zum Beispiel http://192.168.1.50:8096:

  1. Sprache → Benutzer anlegen: einen Namen und ein Passwort (die tippst du auf dem Handy ein).
  2. Mediatheken: „Movies“ → Ordner /media/video, „Music“ → /media/music und, wenn du willst, „Photos“ → /media/photos.
  3. Fernzugriff: eingeschaltet lassen. Fertig.

5. Das OwnMedia-Plugin

In Jellyfin: Dashboard → Plugins → Manage Repositories → +:

  • Name: OwnMedia
  • URL:
{{CATALOG_URL}}

Speichern → zurück zu Plugins, den Filter All wählen (oder suchen) → Homeplay Backup → Install. Dann starte Jellyfin mit dem Knopf Restart auf der Hauptseite des Dashboard neu (nicht unter Plugins). Nach dem Neustart steht das Plugin unter dem Filter Installed, als Active markiert.

Stelle in den Einstellungen von Homeplay Backup den Ordner für Foto-Backups ein: /media/photos.

Neue Versionen des Plugins zeigt Jellyfin von selbst an, unter Plugins.

6. Das Handy

Tippe in OwnMedia auf Add your server: Das NAS wird von selbst gefunden, wenn das Handy im selben WLAN ist. Falls nicht, tippe <NAS-Adresse>:8096 ein. Nimm den Namen und das Passwort aus Schritt 4.

Eine Seite mit QR-Code für Handys: http://<NAS-Adresse>:8096/Homeplay/Phone.

Öffnet sich http://<NAS-Adresse>:8096 nicht im Browser oder findet das Handy das NAS nicht, und die DSM-Firewall ist an (Control Panel → Security → Firewall), füge ihrem Profil eine Allow-Regel für die Ports 8096 (TCP) und 7359 (UDP; darüber finden Handys den Server im WLAN) hinzu.

7. Zugriff aus dem Internet und Einladungen für Freunde (Tailscale)

Nur Jellyfin (Port 8096) wird fürs Internet geöffnet; DSM bleibt geschlossen, und am Router ändert sich nichts.

  1. Package Center → Tailscale → installieren → öffnen → mit deinem Tailscale-Konto anmelden. War Tailscale schon einmal auf diesem NAS, siehst du stattdessen „Your device’s key has expired → Reauthenticate“: Das ist in Ordnung, drück darauf und melde dich an.
  2. Ein Ordner für Aufgabenergebnisse (in Schritt 4 nötig): Lege in der File Station zum Beispiel docker/tasklogs an. Dann Control Panel → Task Scheduler → Settings → Save output results → dieser Ordner.
  3. Task Scheduler → Create → Triggered Task → User-defined script:
    • Reiter General: Name OwnMedia Funnel, Benutzer root, Ereignis Boot-up, Enabled;
    • Reiter Task Settings, Skript:
    /var/packages/Tailscale/target/bin/tailscale funnel --bg 8096

    Beim Speichern warnt DSM vor einer Aufgabe, die als root läuft, und fragt nach dem Passwort deines DSM-Kontos (dem, mit dem du bei DSM angemeldet bist). Halte es bereit.

  4. Wähle die Aufgabe → Run. Das Ergebnis liegt im Ordner aus Schritt 2: <Ordner>/OwnMedia Funnel/<Zeit>/output.log. Dort sollte stehen: 
    Available on the internet:
https://<NAS-Name>.<dein Tailnet>.ts.net/
|-- proxy http://127.0.0.1:8096

    Steht dort stattdessen ein Link zum Aktivieren von Funnel, öffne ihn, drück Enable Funnel und führe die Aufgabe noch einmal aus. Die Einstellung bleibt gespeichert; die Aufgabe beim Hochfahren ist ein Sicherheitsnetz nach einem Neustart des NAS.

  5. Prüfen: Öffne https://<NAS-Name>.<dein Tailnet>.ts.net/Homeplay/Phone auf einem Handy mit ausgeschaltetem WLAN. In den ersten Minuten öffnet sich die Adresse manchmal nicht (ein Fehler bei der sicheren Verbindung): Warte 2–3 Minuten.
  6. In OwnMedia: das Menü des Servers ⋮ → Share with friends → I have an address already → diese Adresse.

Getestet auf einer RS2423+ mit DSM 7.3.2 und dem Tailscale-Paket 1.58.2.

Wenn das Video ruckelt

Finde zuerst heraus, ob der Server das Video umwandelt: Öffne während der Wiedergabe Jellyfin im Browser → Dashboard → das „i“-Symbol neben der Wiedergabe. Direct playing heißt, der Server schickt die Datei, wie sie ist, und der Engpass ist der Weg zum Handy, nicht das NAS.

Wie schnell dieser Weg ist:

  • Zu Hause füge das NAS noch einmal mit seiner Heimadresse (<NAS-Adresse>:8096) zu OwnMedia hinzu und schau darüber: Das Video läuft direkt über das WLAN, mit voller Geschwindigkeit.
  • Unterwegs installiere die Tailscale-App auf dem Handy und melde dich mit demselben Konto an wie auf dem NAS. Dann läuft die Adresse https://….ts.net über Tailscale statt über Funnel.
  • Tailscale verbindet das Handy direkt mit dem NAS oder, wenn der Router das nicht zulässt, über seinen Relay-Server. Über das Relay, wie über Funnel (für Freunde), bekommst du etwa 20 Mbit/s. Das reicht für normale Filme und Serien in 1080p (5–10 Mbit/s), aber nicht für schwere 4K-Dateien: 4K mit 60 Bildern pro Sekunde braucht etwa 40 Mbit/s und ruckelt („spielt 2 Sekunden, wartet 2 Sekunden“).
  • Ob die Verbindung direkt ist, zeigt ein Computer im selben Tailnet: tailscale ping <NAS-Name>; „via DERP“ heißt über das Relay. Eine direkte Verbindung kommt meist mit einem frischen Tailscale-Paket auf dem NAS (im Package Center ist es vielleicht alt; das neue gibt es unter pkgs.tailscale.com) oder mit dem UDP-Port 41641, der am Router des NAS zum NAS hin geöffnet ist (darüber läuft nur der verschlüsselte Verkehr von Tailscale; DSM bleibt geschlossen).

Was du ohne direkte Verbindung mit schweren Dateien machen kannst:

  • lade sie vorher zu Hause herunter: lang drücken → Download, dann aus den Downloads schauen;
  • wähle im Player eine niedrigere Qualität (1080p): Der Server wandelt das Video um. Ein NAS ohne Grafikkarte wandelt mit dem Prozessor um und kommt bei 4K vielleicht nicht mit.

Die App für Freunde

Nichts einzurichten: Die Einladungsseite und der QR-Code schicken Freunde zum Download der neuesten App von ownmedia.app. Dafür braucht es das Plugin 1.8 oder neuer; Jellyfin bietet das Update unter Dashboard → Plugins an.

OwnMedia vom NAS entfernen

  1. Container Manager → Project → ownmedia → Stop → Delete, dann Image → jellyfin/jellyfin → Delete (etwa 1,7 GB).
  2. Task Scheduler → OwnMedia Funnel → Delete. Das schaltet den Zugriff aus dem Internet nicht ab: Funnel bleibt in Tailscale selbst an (die Adresse öffnet sich, mit einem Fehler). Zum Abschalten entferne entweder das Tailscale-Paket (Package Center → Tailscale → Uninstall, dann das NAS aus der Liste Machines auf der Tailscale-Website löschen), oder, wenn du Tailscale für etwas anderes brauchst, führe einmal eine Aufgabe als root aus: /var/packages/Tailscale/target/bin/tailscale funnel --https=443 off.
  3. File Station: Lösche docker/jellyfin und docker/tasklogs. Ist der freigegebene Ordner docker jetzt leer, kannst du ihn unter Control Panel → Shared Folder löschen (beim nächsten Projekt musst du ihn neu anlegen).
  4. Deine Filme, Musik und Foto-Backups bleiben unberührt: Lösch den Backup-Ordner selbst, wenn du ihn nicht brauchst.
  5. In OwnMedia auf dem Handy: das Menü des Servers ⋮ → Server entfernen.
