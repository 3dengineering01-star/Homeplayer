Server für Windows

OwnMediaSetup.exe installiert Jellyfin, fügt deine Ordner hinzu, richtet das OwnMedia-Plugin ein und macht den Server auf Wunsch im Internet erreichbar. Am Ende zeigt es einen QR-Code für dein Handy.

  • Windows 10 oder 11, 64-Bit
  • Administratorrechte, Internet während der Einrichtung
  • Jellyfin schon da? Dann kommt nur das Plugin dazu

NAS und Docker

Lass Jellyfin 12.1 oder neuer in einem Container laufen und füge dann in Jellyfin den OwnMedia-Plugin-Katalog hinzu: Dashboard → Plugins → Manage Repositories → +.

Was das Plugin macht

„Homeplay Backup“ ist die Serverseite von OwnMedia: Es nimmt das Foto-Backup von Handys entgegen, erstellt Einladungslinks für Freunde und zeigt die Seite mit dem QR-Code zum Verbinden eines Handys. Sein Code ist offen, unter der GPL (Quellcode). Neue Versionen erscheinen in Jellyfin von selbst, unter Plugins.
