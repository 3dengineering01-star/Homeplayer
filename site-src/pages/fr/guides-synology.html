OwnMedia sur Synology

Jellyfin dans Container Manager et le plugin OwnMedia depuis le catalogue de plugins. Pas besoin du programme d’installation pour Windows. Environ une demi-heure, une seule fois.

Ce que vous obtenez : les films, séries, musiques et photos du NAS sur votre téléphone, la sauvegarde des photos du téléphone vers le NAS, les invitations pour vos amis et l’accès depuis Internet.

Les menus de DSM, de Jellyfin et de l’app sont cités en anglais, tels qu’ils s’appellent dans l’interface anglaise.

1. Ce NAS peut-il le faire tourner ?

Ouvrez le Package Center et cherchez Container Manager. S’il y est, suivez ce guide.

S’il n’y est pas (petits modèles), Jellyfin existe en paquet SynoCommunity, mais généralement dans une ancienne version, et le plugin OwnMedia demande Jellyfin 12.1 ou plus récent. Dans ce cas, écrivez-nous et nous trouverons une autre solution.

2. Dossiers

Le dossier partagé docker apparaît quand Container Manager est installé. Dans File Station, créez :

  • docker/jellyfin/config et docker/jellyfin/cache pour Jellyfin lui-même ;
  • un dossier pour les photos sauvegardées depuis les téléphones, par exemple photo/OwnMedia.

Laissez vos films, séries et musiques où ils sont ; il vous faut seulement les chemins de leurs dossiers (par exemple /volume1/video, /volume1/music). File Station affiche le chemin : clic droit sur un dossier → Properties.

Chaque dossier a son propre numéro de volume : sur un NAS à plusieurs volumes, docker peut être sur /volume1 et les films et photos sur /volume4. À l’étape 3, saisissez les chemins exactement comme Properties les affiche.

3. Jellyfin dans Container Manager

Container Manager → Project → Create :

  • Project name : ownmedia
  • Path : /volume1/docker/jellyfin
  • Source : Create docker-compose.yml, et collez le fichier ci-dessous. Remplacez les chemins à gauche des deux-points par les vôtres de l’étape 2, numéro de volume compris ; ne touchez pas au côté droit.
services:
  jellyfin:
    image: jellyfin/jellyfin:12.1
    container_name: jellyfin
    # Le réseau du NAS : les téléphones du Wi-Fi trouvent le serveur tout seuls ("Add your server").
    network_mode: host
    restart: unless-stopped
    volumes:
      - /volume1/docker/jellyfin/config:/config
      - /volume1/docker/jellyfin/cache:/cache
      - /volume1/video:/media/video:ro
      - /volume1/music:/media/music:ro
      - /volume1/photo/OwnMedia:/media/photos

Next → Done. Container Manager télécharge Jellyfin (environ 300 Mo) et le démarre.

:ro signifie lecture seule : Jellyfin ne peut rien modifier dans vos films et votre musique. Le dossier des photos n’a pas de :ro, car les sauvegardes du téléphone y sont écrites.

4. Première configuration de Jellyfin

Dans un navigateur sur votre ordinateur, ouvrez http://<adresse du NAS>:8096, la même adresse que pour DSM, par exemple http://192.168.1.50:8096 :

  1. Langue → créez un utilisateur : un nom et un mot de passe (vous les saisirez sur le téléphone).
  2. Bibliothèques : « Movies » → dossier /media/video, « Music » → /media/music, et si vous voulez « Photos » → /media/photos.
  3. Accès à distance : laissez-le activé. Terminé.

5. Le plugin OwnMedia

Dans Jellyfin : Dashboard → Plugins → Manage Repositories → + :

  • Nom : OwnMedia
  • URL :
{{CATALOG_URL}}

Enregistrez → revenez dans Plugins, choisissez le filtre All (ou cherchez) → Homeplay Backup → Install. Redémarrez ensuite Jellyfin avec le bouton Restart de la page principale du Dashboard (pas dans Plugins). Après le redémarrage, le plugin apparaît sous le filtre Installed, marqué Active.

Dans les réglages de Homeplay Backup, indiquez le dossier des sauvegardes de photos : /media/photos.

Jellyfin signale de lui-même les nouvelles versions du plugin, dans Plugins.

6. Le téléphone

Dans OwnMedia, touchez Add your server : le NAS est trouvé tout seul si le téléphone est sur le même Wi-Fi. Sinon, saisissez <adresse du NAS>:8096. Utilisez le nom et le mot de passe de l’étape 4.

Une page avec un QR code pour les téléphones : http://<adresse du NAS>:8096/Homeplay/Phone.

Si http://<adresse du NAS>:8096 ne s’ouvre pas dans le navigateur, ou si le téléphone ne trouve pas le NAS, et que le pare-feu de DSM est actif (Control Panel → Security → Firewall), ajoutez à son profil une règle Allow pour les ports 8096 (TCP) et 7359 (UDP ; les téléphones s’en servent pour trouver le serveur sur le Wi-Fi).

7. Accès depuis Internet et invitations (Tailscale)

Seul Jellyfin (port 8096) est ouvert sur Internet ; DSM reste fermé, et rien ne change sur votre box.

  1. Package Center → Tailscale → installer → ouvrir → connectez-vous avec votre compte Tailscale. Si Tailscale était déjà sur ce NAS, vous verrez plutôt « Your device’s key has expired → Reauthenticate » : c’est normal, appuyez dessus et connectez-vous.
  2. Un dossier pour les résultats des tâches (utile à l’étape 4) : dans File Station, créez par exemple docker/tasklogs. Puis Control Panel → Task Scheduler → Settings → Save output results → ce dossier.
  3. Task Scheduler → Create → Triggered Task → User-defined script :
    • onglet General : nom OwnMedia Funnel, utilisateur root, événement Boot-up, Enabled ;
    • onglet Task Settings, script :
    /var/packages/Tailscale/target/bin/tailscale funnel --bg 8096

    À l’enregistrement, DSM avertit qu’une tâche s’exécute en root et demande le mot de passe de votre compte DSM (celui avec lequel vous êtes connecté à DSM). Gardez-le sous la main.

  4. Sélectionnez la tâche → Run. Le résultat est dans le dossier de l’étape 2 : <dossier>/OwnMedia Funnel/<heure>/output.log. Il doit indiquer : 
    Available on the internet:
https://<nom du NAS>.<votre tailnet>.ts.net/
|-- proxy http://127.0.0.1:8096

    S’il affiche à la place un lien pour activer Funnel, ouvrez-le, appuyez sur Enable Funnel et relancez la tâche. Le réglage est conservé ; la tâche au démarrage est un filet de sécurité après un redémarrage du NAS.

  5. Vérifiez : ouvrez https://<nom du NAS>.<votre tailnet>.ts.net/Homeplay/Phone sur un téléphone avec le Wi-Fi désactivé. Les premières minutes, l’adresse peut parfois refuser de s’ouvrir (erreur de connexion sécurisée) : attendez 2 à 3 minutes.
  6. Dans OwnMedia : le menu du serveur ⋮ → Share with friends → I have an address already → cette adresse.

Testé sur un RS2423+ avec DSM 7.3.2 et le paquet Tailscale 1.58.2.

Si la vidéo saccade

Vérifiez d’abord si le serveur convertit la vidéo : pendant la lecture, ouvrez Jellyfin dans un navigateur → Dashboard → l’icône « i » à côté de la lecture. Direct playing signifie que le serveur envoie le fichier tel quel, et que le goulot d’étranglement est le chemin vers le téléphone, pas le NAS.

La vitesse de ce chemin :

  • À la maison, ajoutez une seconde fois le NAS dans OwnMedia avec son adresse locale (<adresse du NAS>:8096) et regardez par elle : la vidéo passe directement par le Wi-Fi, à pleine vitesse.
  • Hors de chez vous, installez l’app Tailscale sur le téléphone et connectez-vous au même compte que sur le NAS. L’adresse https://….ts.net passe alors par Tailscale et non par Funnel.
  • Tailscale relie le téléphone au NAS directement ou, quand la box ne le permet pas, par son serveur relais. Par le relais, comme par Funnel (pour vos amis), vous obtenez environ 20 Mbit/s. C’est assez pour des films et séries ordinaires en 1080p (5–10 Mbit/s), mais pas pour des fichiers 4K lourds : la 4K à 60 images par seconde demande environ 40 Mbit/s et saccade (« lit 2 secondes, attend 2 secondes »).
  • Un ordinateur du même tailnet indique si la connexion est directe : tailscale ping <nom du NAS> ; « via DERP » signifie par le relais. Une connexion directe vient souvent avec un paquet Tailscale récent sur le NAS (celui du Package Center peut être ancien ; le nouveau est sur pkgs.tailscale.com), ou avec le port UDP 41641 ouvert sur la box du NAS vers le NAS (seul le trafic chiffré de Tailscale y passe ; DSM reste fermé).

Que faire des fichiers lourds sans connexion directe :

  • téléchargez-les à l’avance quand vous êtes à la maison : appui long → Download, puis regardez depuis Downloads ;
  • choisissez une qualité plus basse (1080p) dans le lecteur : le serveur convertit la vidéo. Un NAS sans carte graphique convertit avec le processeur et risque de ne pas suivre en 4K.

L’app pour vos amis

Rien à configurer : la page d’invitation et le QR code envoient vos amis télécharger la dernière app sur ownmedia.app. Il faut pour cela le plugin 1.8 ou plus récent ; Jellyfin propose la mise à jour dans Dashboard → Plugins.

Désinstaller OwnMedia du NAS

  1. Container Manager → Project → ownmedia → Stop → Delete, puis Image → jellyfin/jellyfin → Delete (environ 1,7 Go).
  2. Task Scheduler → OwnMedia Funnel → Delete. Cela ne coupe pas l’accès depuis Internet : Funnel reste actif dans Tailscale (l’adresse s’ouvre, avec une erreur). Pour le couper, soit désinstallez le paquet Tailscale (Package Center → Tailscale → Uninstall, puis retirez le NAS de la liste Machines sur le site de Tailscale), soit, si vous avez besoin de Tailscale pour autre chose, exécutez une fois une tâche en root : /var/packages/Tailscale/target/bin/tailscale funnel --https=443 off.
  3. File Station : supprimez docker/jellyfin et docker/tasklogs. Si le dossier partagé docker est maintenant vide, vous pouvez le supprimer dans Control Panel → Shared Folder (au prochain projet, il faudra le recréer).
  4. Vos films, musiques et sauvegardes de photos ne sont pas touchés : supprimez vous-même le dossier des sauvegardes si vous n’en avez plus besoin.
  5. Dans OwnMedia sur le téléphone : le menu du serveur ⋮ → supprimer le serveur.
