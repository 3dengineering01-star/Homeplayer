Servidor para Windows

OwnMediaSetup.exe instala Jellyfin, añade tus carpetas, pone el plugin de OwnMedia y, si quieres, abre el servidor a internet. Al final muestra un código QR para tu teléfono.

  • Windows 10 u 11, de 64 bits
  • Permisos de administrador, internet durante la instalación
  • ¿Ya tienes Jellyfin? Solo se añade el plugin

Qué hace el plugin

«Homeplay Backup» es la parte del servidor de OwnMedia: recibe la copia de fotos de los teléfonos, crea enlaces de invitación para amigos y muestra la página con el código QR para conectar un teléfono. Su código es abierto, bajo la GPL (código fuente). Las versiones nuevas aparecen solas en Jellyfin, en Plugins.
