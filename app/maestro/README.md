# Сценарии Maestro

Проверка приложения на телефоне без ручных нажатий: [Maestro](https://maestro.mobile.dev) сам нажимает кнопки
и сверяет, что на экране появилось нужное.

Запуск (телефон по USB, на нём уже стоит Homeplay и открыт сервер GOODMAN):

```bash
maestro test app/maestro              # все сценарии по порядку
maestro test app/maestro/02_search.yaml
```

- `01_home` — приложение открывается на сервере, видны библиотеки и поиск.
- `02_search` — общий поиск с каждой буквой: песня, исполнитель, альбом, папка; «2026-10» целиком; имя файла.
- `03_music_search` — поиск в «Музыке» с вкладки исполнителей, числа на вкладках.
- `04_playlist` — плейлист из долгого нажатия, поиск по нему, удаление; на сервере ничего не остаётся.

Сценарии рассчитаны на тестовые файлы сервера GOODMAN (Danheim, Pink Floyd «The Division Bell», фильм Vessels,
фото за 2026-09 и 2026-10). Оформление приложения и настройки телефона они не меняют, `clearState` не
используется: вход на сервер сохраняется.
