## 1. Зачем сайт

1. **Google Play.** Аккаунт разработчика регистрируется на фирму. Google требует сайт разработчика и адрес
   политики конфиденциальности; данные фирмы на сайте должны совпадать с теми, что в Google.
2. **Рассказать о приложении** тем, кто держит дома Jellyfin или Navidrome или уходит с Plex
   (r/jellyfin, r/selfhosted): что это, чем лучше бесплатных приложений, как начать.
3. **Дать всё скачать и настроить:** приложение (Google Play, пока его там нет — запись в бету), установщик
   сервера для Windows, модуль для NAS и Docker, инструкции.

Сейчас на месте сайта — лендинг листа ожидания `landing/index.html` (временно на https://educonsalt.com,
хостинг Hostinger). Его тексты частично устарели (см. раздел 6). Новый сайт его заменяет.

## 2. Что за продукт (кратко, подробно — README.md)

- **OwnMedia** — Android-приложение: музыка, фильмы, сериалы и фото с собственного сервера человека.
  Серверы: Jellyfin (видео, музыка, фото) и Navidrome/Subsonic (музыка).
- Играет почти любой файл как есть, без пережатия на сервере (mpv): MKV, HEVC, AV1, DTS, ASS-субтитры, FLAC.
- Вне дома: через Tailscale, без проброса портов на роутере.
- Копия фото и видео с телефона на свой сервер (модуль сервера «Homeplay Backup»).
- Приглашения друзьям: ссылка или QR-код, друг добавляет сервер одним нажатием, без пароля, только смотрит.
- Загрузки для просмотра без сети, Android Auto для музыки, эквалайзер, оформление «жидкое стекло».
- **Установщик для Windows** (`OwnMediaSetup.exe`): одной программой ставит Jellyfin, модуль, открывает
  доступ из интернета (Tailscale Funnel) и даёт QR-код для телефона.
- **NAS и Docker** (Synology и др.): Jellyfin в контейнере + модуль из каталога модулей
  (`jellyfin-repo/manifest.json`). Инструкция — `docs/synology.md`.
- Без аккаунта OwnMedia, без рекламы, без аналитики: приложение говорит только с серверами пользователя.
- Не связано с Jellyfin, Navidrome, Plex, Tailscale — это обязательная оговорка в подвале.

Цена не решена: **на сайте цен и обещаний «заплати один раз» нет**, пока владелец не решит.

## 3. Страницы

Язык сайта — английский. Структуру сделать так, чтобы потом легко добавить другие языки (отдельные папки

   - Снимки экранов (галерея, листается пальцем на телефоне).

## 5. Оформление и техника

- **Статический сайт:** HTML + CSS, минимум JS (только форма и галерея), без сборщиков и фреймворков, чтобы
  владелец мог залить папку на Hostinger через файловый менеджер. Без внешних скриптов, шрифтов с чужих
  серверов, счётчиков, аналитики и cookie: сайт обещает «no tracking», и это должно быть правдой (тогда и
  баннер про cookie не нужен).
- Стиль — как у приложения: «жидкое стекло» (матовые полупрозрачные карточки с размытием поверх цветного
  фона, светлая кайма), светлая и тёмная тема по системе. Не переусердствовать: текст должен легко читаться,
  проверить контраст (WCAG AA).
- Иконка и логотип — из `docs/brand/` и `docs/play/icon-512.png`; `docs/play/feature-graphic.png` подойдёт
  для превью ссылок (Open Graph). Favicon сделать из иконки.
- **Снимки экранов:** в `docs/play/screenshots/` не заглядывать и оттуда ничего не брать (там личное).
  Поставить аккуратные заглушки в рамке телефона (`site/img/screens/*.webp`, в README сайта — список нужных
  кадров); снимки без личных данных даст владелец.
- Телефон прежде всего: от 360 px ширины без горизонтальной прокрутки, крупные кнопки.
- Lighthouse (мобильный) не ниже 90 по всем четырём пунктам; картинки в WebP с размерами; `lang`, `title`,
  `description`, Open Graph на каждой странице; `sitemap.xml`, `robots.txt`.
- Адрес сайта ещё не выбран (сейчас educonsalt.com). Все ссылки внутри сайта — относительные; полный адрес
  нужен только в `sitemap.xml` и Open Graph — вынести его в одно место, чтобы поменять одной правкой.
