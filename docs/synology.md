# OwnMedia на Synology

Сервер для OwnMedia на NAS Synology: Jellyfin в Container Manager и наш модуль «Homeplay Backup» из
каталога модулей. Установщик для Windows здесь не нужен. Займёт около получаса, один раз.

Что получится: фильмы, сериалы, музыка и фото с NAS на телефоне, копия фото с телефона на NAS,
приглашения друзьям, доступ из интернета.

## 1. Можно ли на этом NAS

Откройте **Центр пакетов** и найдите **Container Manager**. Если он есть — дальше по этой инструкции.

Если его нет (младшие модели), Jellyfin ставится пакетом SynoCommunity, но там обычно старая версия, а
наш модуль работает с Jellyfin 12.1 и новее. В этом случае напишите — подберём другой путь.

## 2. Папки

Общая папка `docker` появляется сама при установке Container Manager. В **File Station** создайте:

- `docker/jellyfin/config` и `docker/jellyfin/cache` — для самого Jellyfin;
- папку для копий фото с телефона, например `photo/OwnMedia`.

Фильмы, сериалы и музыку оставьте там, где они лежат; ниже нужны только пути к их папкам (например,
`/volume1/video`, `/volume1/music`). Путь видно в File Station: правой кнопкой по папке → «Свойства».

Номер тома у каждой папки свой: на NAS с несколькими томами `docker` может быть на `/volume1`, а фильмы
и фото — на `/volume4` и т. п. В шаге 3 подставляйте пути ровно так, как их показали «Свойства».

## 3. Jellyfin в Container Manager

**Container Manager → Проект → Создать**:

- Имя проекта: `ownmedia`
- Путь: `/volume1/docker/jellyfin`
- Источник: «Создать docker-compose.yml», и вставить (пути слева от двоеточия заменить своими из шага 2,
вместе с номером тома; справа — не трогать):

```yaml
services:
  jellyfin:
    image: jellyfin/jellyfin:12.1
    container_name: jellyfin
    # Сеть NAS напрямую: телефон находит сервер в Wi-Fi сам («Add your server»).
    network_mode: host
    restart: unless-stopped
    volumes:
      - /volume1/docker/jellyfin/config:/config
      - /volume1/docker/jellyfin/cache:/cache
      - /volume1/video:/media/video:ro
      - /volume1/music:/media/music:ro
      - /volume1/photo/OwnMedia:/media/photos
```

Далее → Готово. Container Manager скачает Jellyfin (около 300 МБ) и запустит.

`:ro` — только чтение: Jellyfin не может ничего изменить в фильмах и музыке. Папка фото — без `:ro`,
туда записываются копии с телефона.

## 4. Первая настройка Jellyfin

В браузере на компьютере откройте `http://<адрес NAS>:8096` (адрес NAS — тот же, по которому открывается
DSM, например `http://192.168.1.50:8096`):

1. Язык → создать пользователя: имя и пароль (их вы введёте в телефоне).
2. Медиатеки: «Фильмы» → папка `/media/video`, «Музыка» → `/media/music`, при желании «Фото» →
   `/media/photos`.
3. Удалённый доступ — оставить включённым. Готово.

## 5. Модуль OwnMedia

В Jellyfin: **Панель управления → Плагины → Управление репозиториями → +**:

- Имя: `OwnMedia`
- Адрес: `https://raw.githubusercontent.com/3dengineering01-star/Homeplayer/main/jellyfin-repo/manifest.json`

Сохранить → вернуться в **Плагины**, выбрать фильтр **«Все»** (или найти поиском) → **Homeplay Backup** →
Установить. Затем перезапустить Jellyfin: кнопка **«Перезапуск»** на главной странице **Панели управления**
(не в «Плагинах»). После перезапуска модуль в фильтре **«Установлен»** со статусом «Активен».

Там же, в настройках модуля **Homeplay Backup**, укажите папку для копий фото: `/media/photos`.

Новые версии модуля Jellyfin показывает сам, в «Плагинах».

## 6. Телефон

В OwnMedia: **Add your server** — NAS найдётся сам, если телефон в том же Wi-Fi. Если нет — адрес
`<адрес NAS>:8096`. Имя и пароль из шага 4.

Страница с QR-кодом для телефонов: `http://<адрес NAS>:8096/Homeplay/Phone`.

Если в браузере `http://<адрес NAS>:8096` не открывается или телефон не находит NAS, а в DSM включён
брандмауэр (**Панель управления → Безопасность → Брандмауэр**), добавьте в его профиль правило
«Разрешить» для портов 8096 (TCP) и 7359 (UDP; по нему телефон находит сервер в Wi-Fi).

## 7. Доступ из интернета и приглашения друзьям (Tailscale)

Наружу открывается только Jellyfin (порт 8096); DSM остаётся закрытым, на роутере ничего не меняется.

1. **Центр пакетов → Tailscale** → установить → открыть → войти своим аккаунтом Tailscale. Если на NAS
   Tailscale уже когда-то стоял, вместо входа будет «Your device's key has expired → Reauthenticate» —
   это нормально, нажмите и войдите.
2. Папка для результатов задач (понадобится в шаге 4): в **File Station** создайте, например,
   `docker/tasklogs`. Затем **Панель управления → Планировщик задач → Настройки** → «Сохранить
   результаты вывода» → эта папка.
3. **Планировщик задач → Создать → Запущенная задача → Скрипт, заданный пользователем**:
   - вкладка «Общие»: имя `OwnMedia Funnel`, пользователь `root`, событие «Загрузка», «Включено»;
   - вкладка «Настройки задач», сценарий:

     ```sh
     /var/packages/Tailscale/target/bin/tailscale funnel --bg 8096
     ```

   При сохранении DSM предупредит о задаче от `root` и спросит **пароль вашей учётной записи DSM**
   (того, кем вы вошли в DSM) — приготовьте его заранее.
4. Выбрать задачу → **Выполнить**. Результат — в папке из шага 2: `<папка>/OwnMedia Funnel/<время>/output.log`.
   Должно быть:

   ```
   Available on the internet:
   https://<имя NAS>.<ваша сеть>.ts.net/
   |-- proxy http://127.0.0.1:8096
   ```

   Если вместо этого там ссылка на включение Funnel — откройте её, нажмите **Enable Funnel** и выполните
   задачу ещё раз. Настройка сохраняется сама; задача при загрузке — подстраховка после перезагрузки NAS.
5. Проверка: откройте `https://<имя NAS>.<ваша сеть>.ts.net/Homeplay/Phone` на телефоне **с выключенным
   Wi-Fi**. В первые минуты адрес может иногда не открываться (ошибка защищённого соединения) — подождите
   2–3 минуты.
6. В OwnMedia: меню сервера ⋮ → **Share with friends** → «I have an address already» → этот адрес.

Проверено на RS2423+ с DSM 7.3.2 и пакетом Tailscale 1.58.2.

## Если видео тормозит

Сначала узнайте, пересжимает ли сервер видео: во время просмотра Jellyfin в браузере → **Панель
управления** → значок «i» у воспроизведения. «Прямое воспроизведение» значит, что сервер отдаёт файл как
есть, и тормозит путь до телефона, а не NAS.

Скорость пути:

- **Дома** добавьте NAS в OwnMedia ещё раз по домашнему адресу (`<адрес NAS>:8096`) и смотрите через
  него: видео идёт по Wi-Fi напрямую, на полной скорости.
- **Вне дома** поставьте на телефон приложение Tailscale и войдите в тот же аккаунт, что на NAS. Тогда
  адрес `https://….ts.net` идёт через Tailscale, а не через Funnel.
- Tailscale соединяет телефон с NAS напрямую или, если роутер не даёт, через свой сервер-посредник. Через
  посредника, как и через Funnel (у друзей), проходит порядка 20 Мбит/с. Этого хватает для обычных фильмов
  и сериалов 1080p (5–10 Мбит/с), но не для тяжёлых файлов 4K: видео 4K 60 кадров/с весит около 40 Мбит/с
  и будет играть рывками («2 секунды играет — 2 секунды ждёт»).
- Идёт ли связь напрямую, видно на компьютере в той же сети Tailscale: `tailscale ping <имя NAS>` —
  «via DERP» значит через посредника. Прямую связь обычно даёт свежая версия пакета Tailscale на NAS
  (в Центре пакетов бывает старая; новая — на pkgs.tailscale.com) или открытый на роутере сети NAS порт
  UDP 41641 в сторону NAS (через него идёт только зашифрованная связь Tailscale, DSM остаётся закрытым).

Что делать с тяжёлыми файлами, если прямой связи нет:

- скачать заранее, пока вы дома: долгое нажатие → **Download**, потом смотреть из загрузок;
- выбрать в плеере качество ниже (1080p): сервер пересожмёт видео. У NAS без видеокарты пересжатие идёт
  на процессоре, и 4K он может не успевать.

## Приложение для друзей

На Windows установщик кладёт приложение (`OwnMedia.apk`) рядом с модулем, и страница приглашения даёт
его скачать. Из каталога модуль ставится без приложения (оно большое), поэтому страница приглашения
ведёт в Google Play. Пока приложения там нет, положите `OwnMedia.apk` через File Station в папку
модуля: `docker/jellyfin/config/plugins/Homeplay Backup_<версия>/` — страница приглашения и QR-код
сразу начнут давать его скачать.
