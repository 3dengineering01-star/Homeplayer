# Установка Homeplay из APK

Как дать приложение человеку без Google Play: один файл, который ставится на любой Android 7 и новее.

## Собрать файл

На компьютере с тулчейном (нужен `app/android/key.properties` с ключом, см. `docs/play/README.md`):

```bash
./app/build.sh apk
```

Готовый файл: `app/dist/Homeplay-<версия>.apk`. В git он не попадает.

- Перед каждой новой раздачей поднимайте номер сборки в `app/pubspec.yaml` (`version: 0.2.0+2002` →
  `0.2.1+2003`). Тогда новый файл ставится поверх старого, и вход на сервер, настройки и загрузки остаются.
- Подписывайте всегда одним и тем же ключом. Файл с другой подписью Android поверх не поставит, придётся
  удалять приложение вместе с его данными.

Файл можно отправить в Telegram, WhatsApp, по почте или положить в Google Drive.

## Текст для человека, который ставит

Готовое сообщение, можно копировать как есть:

> **Как установить Homeplay**
>
> 1. Откройте на телефоне файл `Homeplay-0.2.0.apk`: нажмите на него в переписке или в «Загрузках».
> 2. Если телефон пишет, что установка из этого источника запрещена, нажмите «Настройки», включите
>    «Разрешить установку из этого источника» и вернитесь назад.
> 3. Нажмите «Установить». Если появится предупреждение Google Play Protect, нажмите «Подробнее» →
>    «Всё равно установить»: приложение не из магазина, поэтому телефон его не знает.
> 4. Откройте Homeplay и нажмите «Add your server». Если телефон подключён к домашнему Wi‑Fi, адрес
>    сервера подставится сам. Введите имя и пароль от сервера и нажмите «Connect».
>
> Новая версия ставится так же, поверх старой: всё сохранится.

## Что может пойти не так

- **«Приложение не установлено».** На телефоне уже стоит Homeplay с другой подписью (например, тестовая
  сборка) или с более новой версией. Удалите старое приложение и поставьте снова.
- **Сервер не находится сам.** Телефон не в домашней сети или роутер не пропускает поиск. Введите адрес
  вручную, например `http://192.168.1.10:8096`.
- **Вне дома** сервер доступен, только если он открыт в интернет (свой домен, VPN вроде Tailscale).
  Тогда в адрес пишется внешний адрес сервера.
