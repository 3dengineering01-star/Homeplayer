# OwnMedia на iPhone

iPhone-версия собирается из того же кода, что и Android-версия (`app/`, Flutter). Сборку делает
Mac от GitHub: `.github/workflows/ios.yml` при каждом изменении в `app/` собирает приложение,
запускает его в симуляторе iPhone и сохраняет файл `OwnMedia-<версия>.ipa`.

## Поставить на свой iPhone бесплатно (Sideloadly, Windows)

Без платного аккаунта Apple Developer. Ограничения: приложение работает 7 дней, потом его надо
переподписать (Sideloadly умеет сам), не больше 3 таких приложений, только на свои устройства.

Один раз:

1. Заведите отдельный бесплатный Apple ID для установки (не основной: Sideloadly — сторонняя
   программа и просит войти).
2. Поставьте iTunes и iCloud **с сайта Apple**, не из Microsoft Store: с версиями из Store
   Sideloadly не видит телефон.
3. Поставьте [Sideloadly](https://sideloadly.io).

Каждая новая версия:

1. GitHub → Actions → iOS → последняя зелёная сборка → Artifacts → **OwnMedia-ipa**, распакуйте zip.
2. Подключите iPhone кабелем, на телефоне нажмите «Доверять этому компьютеру».
3. В Sideloadly перетащите `OwnMedia-<версия>.ipa`, введите Apple ID из шага 1, нажмите Start.
4. Первый раз на iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID →
   «Доверять». На iOS 16 и новее ещё Настройки → Конфиденциальность и безопасность → Режим
   разработчика → включить, телефон перезагрузится.

Если Sideloadly пишет, что идентификатор приложения занят, в Advanced Options включите смену
Bundle ID.

## Что на iPhone не так, как на Android

- Нет фона «Home screen» (обои сквозь приложение) и «Save to phone's Music»: на iPhone нет общей
  папки «Музыка» для других плееров. Для прослушивания без сети — Download.
- Фоновая выгрузка фото: iOS сама решает, когда её запустить, и даёт около 30 секунд за раз;
  файлы докачиваются с места остановки.
- Автопоиск сервера в сети и показ на телевизоре (DLNA) пока не работают: для них Apple должна
  выдать разрешение на multicast (com.apple.developer.networking.multicast). Адрес сервера
  вводится вручную.
- Картинки в картинке и CarPlay пока нет.
- Эквалайзер работает через фильтры mpv (на Android — через эквалайзер системы).

## App Store и TestFlight

Нужен аккаунт Apple Developer ($99 в год). Тогда в сборку добавляется подпись и выгрузка
в App Store Connect.
